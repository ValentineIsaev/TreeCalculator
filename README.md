TreeCalculator - сервис для расчета ветровой нагрузки на деревья.

**Туториал по запуску**
Для запуска подойдут Unix ОС (Ubuntu, AstraLinux, RedOS и другие). 

1. Клонируйте репозиторий в отдельную директорию, используя git clone, либо скачайте файлы вручную и расположите их ровно так, как они хранятся на репозитории.
2. Установите права на запуск для файла install_unix.sh используя команду chmod или любую другую, выполняющую эту функцию на вашей ОС. Запустите файл install_unix.sh.
   **Примечание**:
   Если у вас другой пакетный менеджер (не apt), вам необходимо вручную проделать действия указанные в install_unix.sh.
3. Запустите приложение. Для этого перейдите в корень проекта, затем поочередно в директории TreeBackend и MainBackend и запустите файлы RunBacknd.sh и RunTree.sh. Сначала запустите TreeBackend, затем MainBackend
4. После чего вы можете открыть в браузере страницу приложения по адресу http://127.0.0.1:5600
